# Logic Box

A simple Python project that generates patterns and analyzes number ranges from the terminal.

## Features
- Print triangle and pyramid-style patterns
- Analyze numbers in a chosen range
- Check whether each number is even or odd
- Calculate the sum of numbers in the range

## Run it
```bash
python "Logic Box.py"
```

## Menu options
1. Generate a pattern
2. Analyze a range of numbers
3. Exit

## Example
```text
Select an option:
1. Generate a pattern
2. Analyze a Range of Numbers
3. Exit
```
